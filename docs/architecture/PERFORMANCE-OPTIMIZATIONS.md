# 🚀 Mobile Performance Optimizations - Homepage

**Target:** Improve mobile PageSpeed Insights score from 87 to 90+

---

## ✅ **Completed Optimizations**

### **1. Font Loading (Est. savings: 1,080ms)**

**Problem:** Google Fonts loading synchronously was blocking render.

**Solution:**

- ✅ Removed redundant Google Fonts link from `Base.astro` (fonts are already self-hosted in `global.css`)
- ✅ Added preload hints for critical self-hosted fonts (Noto Sans KR, Bruno Ace SC)
- ✅ Fonts now load with `font-display: swap` (already configured in `global.css`)

**Files Modified:**

- `src/layouts/Base.astro` - Removed Google Fonts, added font preload

---

### **2. Flag SVG Optimization (Est. savings: 3,700+ KiB)**

**Problem:** Mexico flag SVG was 5MB with embedded base64 PNG image.

**Solution:**

- ✅ User replaced both USA and Mexico flag SVGs with optimized versions
- ✅ Reduced from ~5MB to <5KB

**Impact:** Massive reduction in network payload

---

**Problem:** Astro image optimization needed configuration.

**Solution:**

- ✅ Enhanced `astro.config.mjs` with Sharp configuration
- ✅ Added domain and remote pattern support

**Files Modified:**

Open DevTools → Network → Filter by "Font"
